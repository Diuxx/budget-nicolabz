# Pécule

Pécule is a personal budgeting application for planning and tracking monthly
income, expenses, savings, and projects. It runs locally in your browser.

## Features

- Compare planned and actual amounts across monthly and annual views.
- Organize entries by account, funding source, and category.
- Import and export JSON backups or export a spreadsheet.
- Optionally synchronize your budget with Google Drive.

## Quick start

Requires Node.js 20+ and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:8081](http://localhost:8081).
